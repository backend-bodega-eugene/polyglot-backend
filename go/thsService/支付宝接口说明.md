# 天天 App 后端接口说明

给后端实现用。客户端是安装包 `支付宝.apk`，应用内名称「天天」（`__UNI__A538094`，版本 8.7.1）。现在个人信息都写在页面里，接上这些接口后，打开页面改为向后端取值。

Base URL 由后端给出。下面的路径都相对于 Base URL。

## 约定

| 项 | 值 |
| --- | --- |
| Content-Type | `application/json; charset=UTF-8` |
| 鉴权 | 除登录外，请求头带 `Authorization: Bearer {token}` |
| 成功 | HTTP 200，且 `code == 1` |
| 业务失败 | HTTP 200，`code != 1`，`msg` 为可直接提示的文案 |
| 未登录或 token 失效 | HTTP 401，`msg` 如「登录已过期」 |

统一外壳：

```json
{ "code": 1, "msg": "success", "data": {} }
```

金额用字符串，单位元，保留两位小数，不带 `￥`。客户端展示时再加 `￥`。日期按各字段注明的格式返回，不要改成时间戳。

## 接口一览

| 说明 | 方法 | 路径 | 是否登录 |
| --- | --- | --- | --- |
| 登录 | POST | `/api/login` | 否 |
| 我的与账户 | GET | `/api/user/profile` | 是 |
| 参保查询 | GET | `/api/insurance/summary` | 是 |
| 个人缴费记录 | GET | `/api/insurance/records` | 是 |
| 缴费记录详情 | GET | `/api/insurance/record` | 是 |
| 生活缴费户号 | GET | `/api/life/accounts` | 是 |
| 电费 | GET | `/api/utility/electric` | 是 |
| 水费账单 | GET | `/api/utility/water` | 是 |

## 1. 登录

`POST /api/login`

客户端目前没有登录页，接接口时会先走这一步，成功后再请求下面的资料接口。

请求体：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| phone | string | 是 | 手机号 |
| password | string | 是 | 密码 |

成功 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| token | string | 后续请求放在 `Authorization` |
| name | string | 姓名，登录后可先展示 |
| phone | string | 手机号 |

返回示例：

```json
{
  "code": 1,
  "msg": "登录成功",
  "data": {
    "token": "token-string",
    "name": "张三",
    "phone": "18800000000"
  }
}
```

账号或密码错误时 `code` 不为 1，例如 `msg` 为「账号或密码错误」。

## 2. 我的与账户

`GET /api/user/profile`

对应「我的」页的姓名、手机号，以及账户页那一行展示文案。

成功 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| name | string | 姓名。我的页直接显示 |
| phone | string | 手机号。我的页直接显示；需要打码由客户端处理 |
| accountName | string | 账户页姓名，可为脱敏，如 `**好` |
| idNo | string | 账户页证件号，可为脱敏，如 `1**************6` |

客户端把账户页拼成 `accountName|idNo`。

返回示例：

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "name": "张三",
    "phone": "18800000000",
    "accountName": "**好",
    "idNo": "1**************6"
  }
}
```

## 3. 参保查询

`GET /api/insurance/summary`

对应参保查询页。页面上的「参保状态」「查询」是固定文案，不用返回。

成功 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| manageCode | string | 个人编号 |
| cityName | string | 参保城市，如「深圳市」 |
| status | string | 参保状态值，如「参保缴费」 |
| firstDate | string | 首次参保日期，`YYYYMMDD` |
| lastMonth | string | 最后参保年月，`YYYYMM` |
| lastCompany | string | 最后参保单位，可脱敏 |
| monthCount | string | 累计月数 |
| personalAmount | string | 个人缴费累计，两位小数 |
| companyAmount | string | 单位缴费累计，两位小数 |
| interestAmount | string | 利息，两位小数 |

返回示例：

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "manageCode": "1105000022693114",
    "cityName": "深圳市",
    "status": "参保缴费",
    "firstDate": "20070701",
    "lastMonth": "202004",
    "lastCompany": "深********司",
    "monthCount": "75",
    "personalAmount": "15700.32",
    "companyAmount": "0.00",
    "interestAmount": "2000.00"
  }
}
```

## 4. 个人缴费记录

`GET /api/insurance/records`

对应个人查询页的年度列表。

查询参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| year | string | 是 | 四位年份，如 `2025`。客户端年份范围是 2000 到 2026 |

成功 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| manageCode | string | 个人编号，与参保查询同一人 |
| cityName | string | 城市 |
| year | string | 当前查询年 |
| list | array | 该年缴费记录，没有则空数组 |

`list` 每一项：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| month | string | 费款所属期，`YYYYMM` |
| company | string | 单位名称 |
| amount | string | 缴费金额，两位小数，不带 `￥` |
| type | string | 核定类型，如「正常核定」 |

客户端用 `year`、`month`、`company` 拼详情参数。

返回示例：

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "manageCode": "1105000022693114",
    "cityName": "深圳市",
    "year": "2025",
    "list": [
      {
        "month": "202501",
        "company": "深圳市某某公司",
        "amount": "1078.08",
        "type": "正常核定"
      }
    ]
  }
}
```

## 5. 缴费记录详情

`GET /api/insurance/record`

从记录列表点进详情时请求。列表里没有基数、单位缴纳、个人缴纳，这些只在本接口返回。

查询参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| year | string | 是 | 四位年份 |
| month | string | 是 | `YYYYMM` |
| company | string | 是 | 单位名称，与列表中的 `company` 一致 |

成功 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| year | string | 展示用年月。页面当前把所属期放在这个字段，返回 `YYYYMM` 即可 |
| unitName | string | 单位名称 |
| type | string | 核定类型 |
| base | string | 缴费基数，两位小数 |
| total | string | 缴费合计，两位小数 |
| identity | string | 参保身份，如「城镇职工」 |
| companyPay | string | 单位缴纳，两位小数 |
| personalPay | string | 个人缴纳，两位小数 |

返回示例：

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "year": "202501",
    "unitName": "深圳市某某公司",
    "type": "正常核定",
    "base": "4492.00",
    "total": "1078.08",
    "identity": "城镇职工",
    "companyPay": "718.72",
    "personalPay": "359.36"
  }
}
```

查不到该条时 `code` 不为 1，`msg` 说明原因。

## 6. 生活缴费户号

`GET /api/life/accounts`

对应生活缴费页左右两块户名。

成功 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| left | object | 左侧户 |
| right | object | 右侧户 |

每户：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| name | string | 户名，可脱敏，如 `*真明` |
| accountNo | string | 户号，可脱敏 |

客户端拼成 `name|accountNo`。

返回示例：

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "left": { "name": "*真明", "accountNo": "*6666" },
    "right": { "name": "*真明", "accountNo": "*6666" }
  }
}
```

只有一户时，另一侧对象字段返回空字符串。

## 7. 电费

`GET /api/utility/electric`

成功 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| payee | string | 收款单位 |
| amount | string | 应缴金额，两位小数 |
| accountNo | string | 户号 |
| accountName | string | 户名，可脱敏 |
| address | string | 用电地址 |
| supplier | string | 供电单位 |

客户端把户号和户名拼成 `accountNo|accountName`。

返回示例：

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "payee": "深圳供电局有限公司",
    "amount": "0.00",
    "accountNo": "0947000047666294",
    "accountName": "*真明",
    "address": "深圳市龙岗区康达尔花园****C3401",
    "supplier": "深圳供电局"
  }
}
```

## 8. 水费账单

`GET /api/utility/water`

成功 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| amount | string | 应缴金额，两位小数 |
| accountNo | string | 户号 |
| accountName | string | 户名，可脱敏 |
| addressLine1 | string | 地址第一行 |
| addressLine2 | string | 地址第二行，没有则空字符串 |
| supplier | string | 供水单位 |

返回示例：

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "amount": "0.00",
    "accountNo": "1960720096",
    "accountName": "*棠",
    "addressLine1": "龙岗区布吉街道茂业社区康达尔花园蝴蝶****",
    "addressLine2": "座1304",
    "supplier": "深圳市布吉供水有限公司"
  }
}
```
