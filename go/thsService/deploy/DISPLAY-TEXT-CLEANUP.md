# 历史展示文本清理

SQL：`migrations/000020_clean_display_text.up.sql`，MySQL 8，使用utf8mb4连接执行。下一次使用新部署包运行原部署脚本时也会自动应用此迁移；手动执行后再由迁移重复运行不会重复修改已清理记录。

清理用电资料、电费账单description、所得税个人资料、任职单位，以及南网/所得税/支付宝业务记录的展示字段。移除“模拟、测试、演示、仅供展示、仅为展示、仅用于展示、仅作展示、仅限展示”等文字和括号说明；原生成器的提示段落替换为一般服务内容，地址和证件类型使用完整文案。

原内容先保存在`data_text_cleanup_backup`，更新后更换业务version，旧客户端编辑会触发版本冲突。脚本按实际存在的字符串字段处理，保留JSON数字、布尔值、金额、会员账号、标识编号、验证码、URL及审计历史。只修改白名单展示字段，不对整段JSON或数据库所有字段做全局字符串替换。

恢复脚本：`migrations/000020_clean_display_text.down.sql`，恢复备份中的展示字段并生成新版本；恢复完成会删除本次维护备份表。

生成器的业务内容同步更新。API的simulated字段、演示汇率模式以及后台/接口文档说明仍保留，文案调整不改变数据来源或真实对接状态。
