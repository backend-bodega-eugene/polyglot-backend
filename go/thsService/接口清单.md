# 同花顺 App 接口清单

统一入口：`app/utils/api.js`  
基地址：`API_BASE`（当前为空字符串，不发请求，页面用本地 mock）

通用约定：

- 方法未特别说明时均为 **GET**
- 请求超时 8000ms
- 响应可为业务对象本身，也可包一层 `{ data: { ... } }`
- `API_BASE` 为空或请求失败时，前端返回 `null`，页面继续用 `app/mock/` 本地数据
- 当前已接入远程拉取的页面：首页热点选股、推荐/热榜、行情、自选、资讯、理财、持仓/交易资产、持股明细

---

## 一、已预留 HTTP 接口

### 1. 首页热点选股

- 方法 / 路径：`GET /api/home/hot-picks`
- 请求参数：无
- 调用：`fetchHomeHotPicks()`，首页打开时请求
- 响应字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| updatedAt / time | string | 更新时间，如 `09-20 18:13` |
| list | array | 列表，至少 1 条才生效 |

`list[]`：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | number/string | 可选，缺省用下标 |
| title | string | 标题 |
| summary / content / interpret | string | 摘要 |
| ai | boolean | 是否 AI 解读，默认 true |
| related / stocks | array | 关联标的 |

`related[]`：`name`、`code`、`change`

---

### 2. 首页推荐流

- 方法 / 路径：`GET /api/home/feed`
- 请求参数：无
- 调用：`fetchHomeFeed()`，首页推荐组件
- 响应字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| headlines | object | `{ updatedAt, list: [{ id, title }] }` |
| list | array | 推荐动态 |

`list[]` 常用字段：`id`、`type`（news/opinion/media）、`title`、`summary`、`stock{name,code,change}`、`tag`、`time`、`source`、`comments`、`author{name,avatar,time,verified}`、`look`、`shares`、`likes`

至少要有 headlines.list 或 list 之一，否则当失败。

---

### 3. 首页热榜

- 方法 / 路径：`GET /api/home/hot-rank`
- 请求参数：无
- 调用：`fetchHomeHotRank()`
- 响应：`{ list: [...] }` 或直接数组
- `list[]`：`id`、`title`、`hot`、`vote`、`quote`、`stocks[{name,code,change}]`

---

### 4. 行情总览（全球页）

- 方法 / 路径：`GET /api/quotes`
- 请求参数：无
- 调用：`fetchQuotes()`，行情页打开时
- 响应字段（有哪个覆盖哪个）：

| 字段 | 说明 |
|---|---|
| spotIndexes | 现货指数 `[{ name, price, change, pct, cd }]` |
| overseasMoves | 海外异动 `[{ name, code, change, sector }]` |
| aShareIndexes | A股指数 `[{ name, price, change, pct }]` |
| globalBlocks | 全球分组 `{ title, more, cols, items[{ name, price, change, pct, cd, pd, empty }] }` |
| marketLists | 市场榜单对象 |
| aShareMarket | 可内嵌 A股整包（也可用下面独立接口） |
| hkMarket | 可内嵌港股整包 |
| usMarket | 可内嵌美股整包 |

---

### 5. A股行情

- 方法 / 路径：`GET /api/quotes/a-share`
- 请求参数：无
- 调用：`fetchAShareMarket()`
- 至少包含 `indexes` / `ranks` / `status` / `sectorBoard` 之一
- 响应字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| status | string | 如 `开盘中` |
| netInflow | number | 净流入 |
| indexes | array | `{ name, price, change, pct }` |
| downCount / upCount / flatCount | number | 跌/涨/平家数 |
| turnover | number | 成交额 |
| turnoverDelta | number | 成交额变化 |
| briefs | array | `{ id, title, summary }` |
| shortcuts | array | `{ text, key, tone }` |
| compare | object | `limitUp, limitDown, spark[], yesterdayPct, yesterdayName, yesterdayNamePct, largePct, smallPct, sizeHint` |
| rankTabs | string[] | 如 涨幅榜/跌幅榜 |
| ranks | object | key 为榜名，value 为 `[{ name, code, price, change, sector, tag }]` |
| sectorBoard | object | 也可由下一接口单独下发 |

---

### 6. A股板块

- 方法 / 路径：`GET /api/quotes/a-share-sectors`
- 请求参数：无
- 调用：`fetchAShareSectors()`，结果写入 `aShareMarket.sectorBoard`
- 至少包含 `hot` / `stats` / `flow` / `rotate` 之一
- 响应字段：

| 字段 | 说明 |
|---|---|
| hotTabs | `['概念板块','行业板块','指数板块']` |
| hot | 对象，key 为 tab，value 为 `[{ rank, name, code, change, heat }]` |
| statsTabs | `['全部','行业','概念','风格','地域']` |
| statsSorts | `['涨幅','涨速','量比','涨停数']` |
| stats | 对象，key 为 tab，value 为 `[{ name, change, speed, volumeRatio, limitUp, lead, leadChange }]` |
| flow | 资金流相关对象 |
| rotate | 轮动列表 |

### 9. 自选

- 方法 / 路径：`GET /api/watchlist`
- 请求参数：无
- 调用：`fetchWatchlist()`，自选页打开时
- `list` 或 `indexes` 至少一个非空
- 响应字段：

| 字段 | 说明 |
|---|---|
| indexes | `[{ name, code, price, change, pct }]` |
| list | `[{ name, code, price, change, tag, market, extra, pd }]` |

`pd`：价格小数位。`market`：如 `US` / `HK`。`tag`：如 `创` / `融`。`extra`：如 `场内` / `T+0` / `场外`。

资讯详情页目前是占位，可后续接 `articlePage` / `newsPaged`（尚未写入 `api.js`）。详情路由参数：`id`、`title`。

## 二、本地逻辑（尚未预留 HTTP）

这些页面目前只写本地，没有进 `api.js`。对接服务器时可按下面参数开接口。

### 14. 登录（建议 `POST /api/auth/login`）

| 参数 | 必填 | 说明 |
|---|---|---|
| username | 是 | 用户名 / 手机号 |
| password | 是 | 密码 |

当前：`pages/login/login.vue` 只把 `username` 写入本地 `userStore`。

### 15. 注册（建议 `POST /api/auth/register`）

| 参数 | 必填 | 说明 |
|---|---|---|
| username | 是 | 用户名 |
| phone | 否 | 手机号 |
| password | 是 | 密码 |
| confirm | 是 | 确认密码，仅前端校验 |

当前：`pages/register/register.vue` 本地登录。

### 16. 搜索股票（建议 `GET /api/search`）

| 参数 | 位置 | 必填 | 说明 |
|---|---|---|---|
| keyword | query | 否 | 名称或代码，空则返回默认列表 |

响应建议：`[{ name, code, price, change }]`  
当前：`mock/data.js` 的 `searchStocks(keyword)`。

### 17. 加减自选（建议 `POST /api/watchlist/toggle`）

| 参数 | 必填 | 说明 |
|---|---|---|
| code | 是 | 股票代码 |

当前：`sim.js` 的 `toggleWatch(code)`，本地 `sim_v1`。

### 18. 模拟买入（建议 `POST /api/trade/buy`）

| 参数 | 必填 | 说明 |
|---|---|---|
| code | 是 | 代码 |
| name | 否 | 名称 |
| price | 是 | 价格，须 > 0 |
| amount | 是 | 数量，须为 100 的整数倍 |

规则：佣金万一 2.5、最低 5 元；资金不足失败。  
当前：`sim.js` 的 `placeBuy`。

### 19. 模拟卖出（建议 `POST /api/trade/sell`）

| 参数 | 必填 | 说明 |
|---|---|---|
| code | 是 | 代码 |
| name | 否 | 名称 |
| price | 是 | 价格 |
| amount | 是 | 数量，须为 100 的整数倍 |

规则：T+1，当日买入不可卖；卖出另收印花税 0.1%。  
当前：`sim.js` 的 `placeSell`。

## 三、对接方式

1. 在 `app/utils/api.js` 把 `API_BASE` 改成服务器地址，例如 `https://example.com`
2. 服务端按上表路径返回 JSON
3. 有数据就展示接口数据，没有或失败继续用本地 mock
4. 登录 / 搜索 / 买卖若要上服务器，按第二节补接口并改对应页面调用
