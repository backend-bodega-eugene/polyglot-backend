# 南网在线 App 接口说明

从原始安装包 `南网在线.apk` 抽出。应用是 uni-app，appid `__UNI__BA69209`，业务代码在 `assets/apps/__UNI__BA69209/www/app-service.js`。脚本做了字符串表混淆，下面的路径和参数是还原之后的结果。

包里没有抓到真实响应。下面的返回示例按页面实际读取的字段整理，数值仅为示例。

请求分两套主机，IP 都是 `154.64.245.105`。

## 通用约定

### 南网业务接口，端口 3979

| 项 | 值 |
| --- | --- |
| Base URL | `http://154.64.245.105:3979` |
| 方法 | 默认 `POST`。地址以 `http` 开头时不再拼接 Base URL |
| Content-Type | `application/json; charset=UTF-8` |
| User-Agent | `nwzx` |
| device / osType / version | `android` / `ANDROID` / `5.0.0` |
| x-auth-token、authorization | 都是配置里的 `camsid` |
| Cookie | `CAMSID={camsid}` |
| deviceId | 配置里的 `deviceId` |
| channelcode | 只有调用方传入时才加到请求头 |

内置配置（`getConfig()`，地区码可被 `setAreaCode` 改掉）：

| 字段 | 值 |
| --- | --- |
| camsid | `98D542D550155D680CCB6884F0DE4637` |
| deviceId | `abeJF/wo0ScDAPokuU3Bm+lv` |
| userId | `NW00004453361991` |
| areaCode | `050200` |

HTTP 200 时 Promise 一律 resolve 响应体。`sta === "00"` 视为业务成功，否则控制台打出 `sta` 和 `message`。

### 账号与账单接口，端口 3980

| 项 | 值 |
| --- | --- |
| Base URL | `http://154.64.245.105:3980` |
| 成功 | HTTP 200 且 `code === 0` |

登录请求单独带 `Content-Type: application/json`。用户、账单接口没有带 3979 那套请求头。

## 账号与账单

### 1. 登录

- `POST http://154.64.245.105:3980/api/login`
- 页面：`pages/login/index`。手机号、密码都为空时直接提示，不发请求

| 参数 | 位置 | 必填 | 说明 |
| --- | --- | --- | --- |
| username | body | 是 | 页面字段名是 `phone` |
| password | body | 是 | 密码 |

成功后把 `data` 写入 `loginUser`，并写入 `isLoggedIn=true`、`loginPhone`，然后回到首页。失败提示「账号或密码错误」。

返回示例：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "id": 1,
    "username": "13800000000",
    "display_name": "张三",
    "address": "深圳市龙华区示例路 1 号",
    "user_id_number": "0943000049338409",
    "supplier": "光明供电局",
    "meter_reader": "李明",
    "meter_no": "1703010295",
    "postal_code": "518126"
  }
}
```

### 2. 按 id 取用户

- `GET http://154.64.245.105:3980/api/users/{id}`
- `id` 来自 `loginUser.id`
- 首页拉资料，以及 App 启动后每 15 秒同步一次

`data` 里页面用到的字段：

| 字段 | 说明 |
| --- | --- |
| id | 用户 id，也是账单路径参数 |
| username | 登录名 |
| display_name | 展示姓名，没有则用 username |
| address | 地址 |
| user_id_number | 户号。前 10 位、剩余部分拆成前缀和后缀 |
| supplier | 供电单位 |
| meter_reader | 抄表员 |
| meter_no | 表号。前 5 位、剩余部分拆开 |
| postal_code | 邮编 |

返回示例：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "id": 1,
    "username": "13800000000",
    "display_name": "张三",
    "address": "深圳市龙华区示例路 1 号",
    "user_id_number": "0943000049338409",
    "supplier": "光明供电局",
    "meter_reader": "李明",
    "meter_no": "1703010295",
    "postal_code": "518126"
  }
}
```

### 3. 按手机号查用户

- `GET http://154.64.245.105:3980/api/users?keyword={phone}`
- 本地没有 `loginUser.id`、但有 `loginPhone` 时才会请求

`data.list` 里优先找 `username` 等于该手机号的记录，找不到就用第一条，再存进 `loginUser`。用户对象字段与「按 id 取用户」相同。

返回示例：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "list": [
      {
        "id": 1,
        "username": "13800000000",
        "display_name": "张三",
        "address": "深圳市龙华区示例路 1 号",
        "user_id_number": "0943000049338409",
        "supplier": "光明供电局",
        "meter_reader": "李明",
        "meter_no": "1703010295",
        "postal_code": "518126"
      }
    ]
  }
}
```

### 4. 电费账单

- `GET http://154.64.245.105:3980/api/bills/{userId}`
- 调用页：账单列表、用电日历、首页最近一笔、缴费记录
- `userId` 是 `loginUser.id`

返回兼容三种形状：`data` 为数组、`data.data` 为数组，或响应体本身就是数组。

| 字段 | 说明 |
| --- | --- |
| code | 账期 `YYYYMM`。账单列表丢掉大于等于当前月的记录，并按 code 倒序取最近一笔 |
| bill_month | 缴费记录在没有 code 时使用 |
| start_date / end_date | 计费起止，拼成 `start~end` |
| amount | 金额 |
| total_usage | 用电量 |
| detail | 字符串则 `JSON.parse`，否则当对象 |

返回示例：

```json
{
  "code": 0,
  "msg": "success",
  "data": [
    {
      "code": "202508",
      "bill_month": "202508",
      "start_date": "2025-08-01",
      "end_date": "2025-08-31",
      "amount": 128.56,
      "total_usage": 210,
      "detail": {}
    }
  ]
}
```

`amount` 在页面里会调用 `toFixed`，按数字返回。

## 南网业务接口

相对路径拼在 `http://154.64.245.105:3979` 后面，方法都是 POST，body 为下表。未写参数的接口 body 是 `{}`。

| 客户端方法 | 路径 | 参数 |
| --- | --- | --- |
| queryHotNews | `/mp/ucs/ma/zt/content/queryHotInformations` | `areaCode`，`count` 字符串，默认 `"3"`，资讯页传 `"10"` |
| queryInformationList | `/mp/ucs/ma/zt/content/queryInformationInfos` | `areaCode`，`classId`，`pageNo` 默认 `"1"`，`pageSize` 默认 `"10"` |
| queryLatestInformations | `/mp/ucs/ma/zt/content/queryLatestInformations` | `areaCode`，`count` 默认 `"10"` |
| queryInformationDetail | `/mp/ucs/ma/zt/content/queryInformationInfoDetail` | `id` |
| queryRecommendUsers | `/mp/w2/wx/portal/eleCustNumber/queryRecommendUsers` | 无 |
| queryBindEleUsers | `/mp/w2/wx/portal/eleCustNumber/queryBindEleUsers` | 无 |
| queryNearbyHalls | `/mp/ucs/ma/businesshall/businessHall/queryBusinessHallNearby` | `longitude`、`latitude`，都转成字符串 |
| queryUnreadMessages | `/mp/ucs/ma/intramsg/txhMsg/queryUnreadTitleList` | 无 |
| queryBindArrearsList | `/mp/w2/wx/elecmanageImp/electric-fee/queryBindArrearsList` | 无业务 body。请求头额外带 `channelcode: 4` |
| queryMeteringPointList | `/mp/w2/wx/elecmanageImp/electric-fee/queryMeteringPointList` | 有户号时 `{ eleCustId }`，否则 `{}` |
| checkChargingPile | `/mp/w2/wx/elecmanageImp/electric-daily/checkChargingPile` | 无 |

资讯列表（热点、分类列表共用解析）在 `sta === "00"` 时读 `data` 数组，没有数组就读 `data.dataList`：

| 字段 | 说明 |
| --- | --- |
| id / title | 编号、标题 |
| issuedName / source | 来源 |
| publishTime / createTime | 时间 |
| imgUrl / coverUrl | 封面 |
| link | 外链 |
| readCount | 阅读数 |

欠费列表 `queryBindArrearsList` 在 `sta === "00"` 时把 `data` 映射为户号：

| 字段 | 说明 |
| --- | --- |
| userName / custName | 户名 |
| eleCustId / custNo | 户号 |
| address / eleAddr | 地址 |
| arrears / totalArrears | 欠费 |
| eleCustNumberId | 户号记录 id |
| message | `sta` 不是 00 时日志输出 |

南网业务接口统一外壳。`sta` 不是 `"00"` 时页面不当成功。

```json
{
  "sta": "00",
  "message": "success",
  "data": {}
}
```

资讯类（`queryHotNews`、`queryInformationList`、`queryLatestInformations`）在 `sta` 为 `"00"` 时，`data` 为数组；不是数组时改读 `data.dataList`。

返回示例：

```json
{
  "sta": "00",
  "message": "success",
  "data": [
    {
      "id": "1001",
      "title": "停电检修通知",
      "issuedName": "南网在线",
      "source": "",
      "publishTime": "2026-08-01 10:00:00",
      "createTime": "2026-08-01 09:30:00",
      "imgUrl": "https://example.com/news.jpg",
      "coverUrl": "",
      "link": "",
      "readCount": 12
    }
  ]
}
```

`queryInformationDetail` 的请求体是 `{ "id": "1001" }`。页面没有再拆详情字段，成功时同样看 `sta`。

返回示例：

```json
{
  "sta": "00",
  "message": "success",
  "data": {
    "id": "1001",
    "title": "停电检修通知",
    "content": "详情正文"
  }
}
```

`queryBindArrearsList` 返回示例：

```json
{
  "sta": "00",
  "message": "success",
  "data": [
    {
      "userName": "张三",
      "custName": "张三",
```

返回示例：

```json
  "message": "success",

    {
      "userName": "张三",
```

返回示例：

返回示例：

`checkChargingPile` 请求体为 `{}`。

返回示例：

```json
{
  "sta": "00",
  "message": "success",

    "hasPile": false
  }
}
```

附近营业厅、未读消息、计量点、充电桩、资讯详情这几类，页面没有点名字段。示例里的业务字段只用于说明外壳，客户端目前会忽略未读取的字段。
